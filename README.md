# TrafficCounter

Road traffic monitoring and session logging system for macOS.

- **SwiftUI** front end for camera selection, live feed, and session review.
- **Python** computer-vision handler for frame processing and vehicle counting.
- **PostgreSQL** for persistent session storage.
